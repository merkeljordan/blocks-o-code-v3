The Problem

❌ The Problem

Programming is abstract and inaccessible.

Beginners face an invisible barrier — a blank text editor with zero feedback. There's no physical intuition for loops, branches, or sequences. Most give up before writing a single meaningful program.

→
✅ Our Solution

Make programming tangible, immediate, and fun.

Users snap together magnetic hardware blocks to build a program. No keyboard. No screen. The physical arrangement is the code — and it executes with real LEDs, real audio, and real interactivity.

Goal: A working end-to-end system where 15 physical blocks snap together, a Brain reads the arrangement, validates it as a legal program, and executes it — all in real time.

Key Requirements

Functional Requirements
  • Detect which blocks are physically connected and in what order
  • Validate the block sequence against program grammar rules
  • Execute the program on command (LEDs, audio, display)
  • Provide real-time feedback: app updates within scan interval
  • Support control flow (If/Loop), input (Button), and output blocks
  • Preview block configuration on-block before execution

Brain Block — Deep Dive

Adaptive Scan + Event Handler
  • Dedicated block_cfg_scan task walks I2C addresses 0x08 – 0x16 with fast re-scan after adds/removals
  • Config Manager compares to previous state, smoothing unstable REG_WHOAMI results with last-known-good type
  • On change → JSON config cached under a mutex and BLOCK_CONFIG_CHANGED event bit set
  • tcp_client_task wakes on that event and streams the latest JSON to the app
I2C Commands (sent to child blocks)
CMD_PING CMD_SET_LED CMD_EXECUTE CMD_RESET CMD_GET_DATA CMD_MATRIX_BRIGHTNESS

Flutter App — Validation Engine

4 Enforced Grammar Rules
  • Rule 1 — Brain Block must exist and be at index 0
  • Rule 2 — If sequences: If → ButtonPress → Then → [Output+] → End If
  • Rule 3 — Loop sequences: Loop → [Output+] → End Loop
  • Rule 4 — Interleaved sequences trigger a warning
App Features
  • TCP server on port 41233, heartbeat with 60s timeout
  • Exponential backoff reconnect (max 5 attempts)
  • Offline testing via fake JSON asset loading
  • 3D isometric block-chain visualizer (Windows)
  • Telemetry log (last 100 entries)
