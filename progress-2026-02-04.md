## LED Color Flash Block
Scaffolded `firmware/esp32/block_templates/led_color_flash_block` with:
- Project CMake (`CMakeLists.txt`) and component CMake in `main/`.
- `main.c`, `i2c_comm.c`, `command_handler.c`, `led_matrix.c`, `speaker.c`, `speaker.h`.
- Block type set to `BLOCK_TYPE_LED_FLASH`.

LED Color Flash behavior added:
- `color_id` (uint8) stored as the config payload.
- `CMD_SET_LED` with 1-byte payload sets `color_id` and flashes the matrix as preview.
- `CMD_EXECUTE` flashes the currently selected color.
- `CMD_GET_DATA` returns the 1-byte `color_id`.
