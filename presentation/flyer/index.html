ECE Senior Design Project

Blocks o' Code

Physical, tangible programming blocks — the blocks are the code

🧩
15 Modular Blocks
Physical blocks with TFT touchscreens and LED matrices. Each block is an I2C slave with its own ESP32 microcontroller. Snap them together to build real programs.
⚡
Real-Time Execution
The Brain Block scans, discovers, and orchestrates all connected blocks. Supports IF/THEN/LOOP control flow, button inputs, music, LEDs, and more.
📱
Companion App
Cross-platform Flutter app connects via TCP/WiFi. Validates block sequences in real-time with a dynamic rule engine and visual block topology display.
